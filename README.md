## Short Project Description
Next Gadgets is a modern e-commerce inspired platform built with Next.js 13 (App Router).  
It includes a responsive Navbar, Hero section, Product Highlights, and Footer.  
This project demonstrates Server & Client components, routing, and production-ready deployment.
